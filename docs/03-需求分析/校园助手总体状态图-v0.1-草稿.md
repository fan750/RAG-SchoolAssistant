# 校园助手总体状态图 v0.1 草稿

![校园助手总体状态图](校园助手总体状态图-v0.1.svg)

- **公开资料**定时同步。系统解析公开指南和公告，管理员审核后发布到校园信息和问答。
- **同济校历**走官方 API，按日期查询工作日、周末或假期。[同济校历 API 文档](https://api.tongji.edu.cn/docs/interface/teaching_management_data/educational_administration_data/term_calendar_info/v1_rt_onetongji_calendar)
- **图书馆**首版展示分馆开放时间和官方预约入口。余座查询待确认接口并获得授权。接入后显示当前可预约座位数及采样时间。[分馆开放时间](https://www.lib.tongji.edu.cn/index.php?classid=12772) · [图书馆余座服务说明](https://www.lib.tongji.edu.cn/index.php?classid=11979&newsid=34915&t=show)
- **访客与师生**可以浏览已确认的校园信息。师生通过校园统一认证后可以向 Agent 提问，回答附来源。

## 模型检查

TLC 检查了 144 个可达状态，验证了资料审核后才发布、校历结果来自官方 API、图书馆首版保留开放时间与官方预约入口、余座查询须获授权、余座结果带采样时间、登录后才可提问，以及无死锁。图省略了 6 个停留在原状态的结束迁移。

模型覆盖一次同步、一次校历查询和一次余座查询。接口失败、公告版本更新和部署细节留待后续设计。这是设计草稿，检查结果只适用于模型。

## 重新生成

从仓库根目录运行。把 `STATECHART` 的值替换为本机 statechart 技能中 `scripts/statechart` 的路径。如果已有 TLC jar，可通过 `TLA2TOOLS` 指定。

```sh
STATECHART="/path/to/statechart/scripts/statechart"
model="models/状态图/校园助手总体状态图"
scratch="$(mktemp -d)"

"$STATECHART" "$model/CampusData.tla" \
	--config "$model/CampusData.cfg" --view "$model/campus-data-view.mjs" \
	--out "$scratch/out" &&
npm install --prefix "$scratch" --no-audit --no-fund pele@1.9.0 &&
cp "$model/render.mjs" "$scratch/render.mjs" &&
node "$scratch/render.mjs" "$scratch/out/chart.mmd"
```

生成的 Mermaid、SVG 和检查报告位于 `$scratch/out`。如果命令返回非零退出码，或报告中有未通过的规则，先检查报告与 TLC 日志。
